# لعبة الحاجات والرغبات

تطبيق ويب بسيط باللغة العربية يساعد المتعلمين على التمييز بين **الاحتياجات** و**الرغبات** من خلال لعبة من 20 جملة.

## كيفية التشغيل محليًا
1. حمل أو استنسخ هذا المستودع إلى جهازك.
2. افتح الملف `index.html` في متصفح حديث (Chrome، Firefox، Edge...).
3. اضغط على زر "ابدأ اللعبة" وابدأ في الاختيار بين الاحتياج والرغبة لكل جملة.

> لا تحتاج إلى أي خادم أو تثبيتات إضافية؛ الملفات ثابتة بالكامل.

## استضافة مجانية عبر GitHub Pages
يمكنك نشر اللعبة مجانًا باستخدام **GitHub Pages**:

1. أنشئ مستودعًا جديدًا على GitHub وادفع (push) ملفات المشروع إليه.
2. من إعدادات المستودع، انتقل إلى قسم **Pages**.
3. اختر الفرع `main` (أو الفرع الذي رفعت الملفات إليه) وحدد مجلد الجذر `/` كمصدر.
4. احفظ الإعدادات، وبعد لحظات ستحصل على رابط عام للعبة.

> أي تعديل لاحق تدفعه إلى الفرع المحدد سيتم نشره تلقائيًا.

## بنية المشروع
```
├── index.html   # صفحة اللعبة الرئيسية
├── style.css    # تنسيقات الواجهة
└── script.js    # منطق اللعبة باستخدام JavaScript
```
